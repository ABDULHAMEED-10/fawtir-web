# Reports, Activity (TDD & OTA) and Documents: design realignment, backend asks

The product owner's ruling (27 Sep 2026): the Figma frames are the source of truth and the backend
adapts to them. Each screen was put back on its frame; where the API does not carry what the frame
draws, the screen draws it from the best value the data allows (or a marked placeholder behind a
`// TODO(backend)` comment) and the gap is listed here. One section per screen group; rows are
`| n.m | what the UI draws | what the backend must add |`. Append only.

## 1. Reports (`GET /v1/reports/volume`, `/expenditure`, `/cash-flow`, `/vat`, `/lists`, the `.csv`/`.xlsx` exports, `GET /v1/compliance/activity/summary`)

Every page reads a monthly history (1 January two years back to today) and cuts the frame's shapes from it: the pill's window and the one before it for the four figures, the trailing twelve months, quarters and years. The ranked cards read the server's own grouping over the pill's window. `tools/mock-api/routes/reports.mjs` answers all five report routes.
